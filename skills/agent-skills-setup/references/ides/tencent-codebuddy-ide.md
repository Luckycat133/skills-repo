# tencent-codebuddy-ide (standalone IDE)

MCP is Settings/UI-managed with `mcpServers`, but no portable file is documented. Project rules use `.codebuddy/rules/<name>/RULE.mdc`; project Skills use `.codebuddy/skills/`; `CODEBUDDY.md` is context with `AGENTS.md` fallback. Commands, agents, hooks, memory, and user Skills are manual. Do not reuse CodeBuddy CLI paths.

Sources: [IDE Skills](https://www.codebuddy.cn/docs/ide/Features/Skills), [rules](https://www.codebuddy.cn/docs/ide/User-guide/Rules), [MCP](https://www.codebuddy.cn/docs/ide/User-guide/MCP).
