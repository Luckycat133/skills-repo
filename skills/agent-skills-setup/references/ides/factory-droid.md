# factory-droid

Factory Droid uses `.factory/skills/` and `~/.factory/skills/`, hierarchical `AGENTS.md`, `.factory/mcp.json` and `~/.factory/mcp.json`, custom droids under `.factory/droids/` or `~/.factory/droids/`, and hooks in layered settings.

Skills and reviewed MCP server maps are portable. Custom droids require a manual agent template; hooks can only be generated disabled and must never be activated by migration.

Sources: [MCP](https://factory.mintlify.app/cli/configuration/mcp), [hooks](https://factory.mintlify.app/cli/configuration/hooks-guide), [custom droids](https://factory.mintlify.app/cli/configuration/custom-droids).
