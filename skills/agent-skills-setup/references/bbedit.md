# BBEdit MCP Setup

Configure MCP in BBEdit via extension.

## MCP Support Level

Partial - uses extension-based approach

## Extension Method

1. Install BBEdit MCP extension from extensions gallery
2. Configure MCP servers via extension preferences

## Alternative: Shell Integration

BBEdit supports AppleScript and shell scripts that can invoke MCP servers.

## Limitations

BBEdit is a traditional text editor. Full MCP integration requires third-party extensions.

## Recommended Alternatives for Full MCP

- **Cascade (Windsurf)** - Full MCP support
- **Zed** - Full MCP support
- **VS Code + Continue** - Full MCP support
