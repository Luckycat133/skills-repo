# Support

Report the exact source/target product and profile, versions when known, requested
scope, subcommand (`inspect`, `migrate`, `export-device`, `import-device`, or
`patch-mcp`), expected result, and a minimal redacted before/after example. Never paste
API keys, `.env` values, raw configuration files, or session data — public issues are
not automatically sanitized.

This is an agent-guidance Skill with a local stdlib helper (`scripts/migrate_context.py`),
not a hosted migration service. Marketplace copies may differ from this unreleased
branch; include where the Skill was installed.

Voluntary funding links are configured separately in `.github/FUNDING.yml`.
No payment, star, account registration, or external upload is needed for migration.
No paid-service pricing or availability is promised by this document.
