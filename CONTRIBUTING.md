# Contributing

Read [AGENTS.md](AGENTS.md) and the [development Skill](dev/skills/maintain-agent-skills-setup/SKILL.md).
Improve one observable migration behavior with vendor evidence and a focused case.
Do not rebuild the retired engine or claim compatibility from product counts.

Run `bash validate-all.sh`. Keep fixtures isolated, with no real credentials or
home-directory access. State whether testing was structural, guided fixture,
real-host discovery, or runtime. Unavailable checks remain not run.

Open a focused PR. Preserve existing main protection and do not publish releases
or marketplace packages without maintainer authorization.
