This folder archives review reports for **user-level skills** (installed under
`~/.workbuddy/skills/`), kept separate from `docs/agent-skills-setup/` which holds
development and planning docs for this repository's own publishable skill.

本目录归档**用户级技能**（位于 `~/.workbuddy/skills/`）的审查报告，
与 `docs/agent-skills-setup/` 分开——后者是本仓库自有可发布技能的开发/规划文档。

## Reports / 报告

- `agent-team-orchestration.md` — review of the `agent-team-orchestration` skill
- `trae-code-review.md` — review of the `TRAE-code-review` skill

## Convention / 约定

- Reviews are archived here, not inside the reviewed skill's own directory.
- 审查报告归档于此，不写入被审查技能自身的目录。
