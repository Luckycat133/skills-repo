# train_data — 训练集

> **用途**：模型参数拟合（learning）。同时作为划分的**原始数据入口**。

---

## 1. 数据来源（Data Source）
- **来源说明**：_（采集渠道 / 上游系统 / 采样时间窗）_
- **占比**：划分后约占总数据的 **50%–65%**（在扣除 test 与 validation 之后的剩余部分）。
- **原始入口**：将完整带标签数据放入 `raw/full_dataset.csv`，由划分脚本切出三集合。

## 2. 数据格式（Format）
- **文件格式**：_（如 CSV / Parquet / JSONL）_
- **编码**：UTF-8
- **文件位置**：
  - `raw/`：原始全量/训练数据（不可变源）
  - `processed/`：清洗与特征工程后的训练数据
  - `metadata/`：schema、特征字典、标签映射、统计摘要

## 3. 特征含义（Feature Dictionary）
| 字段名 | 类型 | 含义 | 取值范围/单位 | 备注 |
|--------|------|------|----------------|------|
| id | string | 样本唯一标识 | — | 不参与建模 |
| feature_1 | float | _（示例）_ | _（示例）_ | |
| ... | ... | ... | ... | |
| label | int/str | 目标标签 | _（示例）_ | 训练目标 |

> 完整版建议维护在 `metadata/feature_dictionary.md`。

## 4. 划分方法（Split Method）
- 本目录 `raw/` 是划分的输入源；`train_data/processed/` 存放划分产出的训练切片。
- 预处理管道（缺失值填充、标准化、编码等）应**仅在训练集上 fit**，再 transform 到验证/测试集，避免数据泄漏。

## 5. 使用约束
- `raw/` 视为只读；所有变换写入 `processed/`。
