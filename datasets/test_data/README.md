# test_data — 测试集

> **用途**：模型开发完成后进行**一次性、无偏**的最终性能评估。
> **红线**：训练、调参、特征选择、模型选择的任何环节都**不得接触**本目录。

---

## 1. 数据来源（Data Source）
- **来源说明**：_（填写：采集渠道 / 上游系统 / 采样时间窗 / 是否独立留出集）_
- **独立性**：测试集应尽量来自与训练数据**独立的分布或时间段**（如按时间切分的未来数据），以更真实地反映泛化能力。
- **占比**：约占独立数据的 **20%–30%**（详见根目录 `DATA_USAGE_GUIDE.md`）。

## 2. 数据格式（Format）
- **文件格式**：_（如 CSV / Parquet / JSONL / 图像目录）_
- **编码**：UTF-8
- **文件位置**：
  - `raw/`：原始测试数据（不可修改）
  - `processed/`：与训练同一套预处理管道产出的可评估数据
  - `metadata/`：schema、特征字典、标签映射

## 3. 特征含义（Feature Dictionary）
| 字段名 | 类型 | 含义 | 取值范围/单位 | 备注 |
|--------|------|------|----------------|------|
| id | string | 样本唯一标识 | — | 不参与建模 |
| feature_1 | float | _（示例）_ | _（示例）_ | |
| ... | ... | ... | ... | |
| label | int/str | 目标标签 | _（示例）_ | 评估目标 |

> 完整版建议维护在 `metadata/feature_dictionary.md`。

## 4. 划分方法（Split Method）
- **方法**：分层随机抽样（stratified random sampling），保证与训练标签分布一致。
- **随机种子**：`42`（固定以保证可复现）
- **生成命令**：见根目录 `scripts/split_dataset.py`
- **一致性校验**：`scripts/verify_distribution.py` 通过后方可使用。

## 5. 使用约束
- 只在最终评估阶段读取，**评估次数尽量为一次**。
- 严禁据测试集结果反复迭代模型（否则等同泄漏）。
